# Security

Please do not report vulnerabilities in public issues or pull requests.
Follow the private reporting instructions in
[LangChain's security policy](https://github.com/langchain-ai/langchain/security/policy).
Include affected versions, a reproduction, and the potential impact.

Until 1.0, security fixes target the latest published minor release. After 1.0,
security fixes target the latest stable major release. Upgrade to the latest
patch in that line; older releases are not maintained separately.
