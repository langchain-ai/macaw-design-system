# Security Policy

Please do not report vulnerabilities in public issues or pull requests.

Report vulnerabilities through the
[LangChain Open Source Vulnerability Disclosure Program](https://app.intigriti.com/researcher/programs/langchain/langchain-open-source-vdp),
as directed by [LangChain's security policy](https://github.com/langchain-ai/.github/blob/main/SECURITY.md).
Include the affected package version, steps to reproduce, and the potential
impact. Follow the program's scope and reporting guidelines.
