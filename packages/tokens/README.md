# Macaw tokens

Framework-independent design tokens with no runtime dependencies.

```sh
pnpm add @langchain/macaw-tokens
```

```css
@import '@langchain/macaw-tokens/tokens.css';
```

Use semantic CSS custom properties and add `dark` to `html` for the dark theme.
`/tokens.json` exports the same values and selectors for tooling. Read the
[token reference](docs/TOKENS.md) for details.

When using Macaw components, their stylesheet already includes these tokens.
